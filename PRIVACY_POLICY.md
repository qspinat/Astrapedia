# Privacy Policy

**Astrapedia** — Interactive 3D Celestial Sphere
**Last updated:** February 8, 2026

## Overview

Astrapedia is an open-source educational astronomy application. We are committed to protecting your privacy. This policy explains what data the app accesses and how it is used.

## Data We Collect

**We do not collect, store, or transmit any personal data.** There are no accounts, no analytics, no tracking, and no advertising.

## Location Data

Astrapedia requests access to your device's location (GPS) to:

- Calculate which celestial objects are visible from your position
- Display the local horizon and cardinal directions
- Compute altitude/azimuth coordinates for stars and planets

**Your location data is processed entirely on your device.** It is never sent to our servers (we don't have any), never shared with third parties, and never stored beyond the current session.

You can use the app without granting location permission — it will default to a fixed location.

## Internet Access

The app uses an internet connection to fetch publicly available astronomical data and images from the following sources:

| Service | Purpose |
|---------|---------|
| VizieR (CDS, Strasbourg) | Additional star catalog data when zoomed in |
| SIMBAD (CDS, Strasbourg) | Deep-sky object information |
| NASA Images API | Telescope images of celestial objects |
| ESA/Hubble CDN | Hubble telescope images |
| ESA/Webb CDN | James Webb telescope images |
| Wikimedia Commons | Object images (ESO/ESA) |
| CDS HiPS (Aladin Sky Atlas) | Digitized Sky Survey fallback images |

These requests contain only astronomical queries (e.g., coordinates, object names). **No personal data, device identifiers, or location information is included in these requests.**

Each of these services has its own privacy policy governing how they handle incoming requests.

## Data Storage

Astrapedia stores user preferences (e.g., language, magnitude settings) using your browser's or device's local storage. This data never leaves your device.

## Children's Privacy

Astrapedia does not collect any data from anyone, including children. The app is suitable for all ages.

## Changes to This Policy

If this policy is updated, the changes will be posted here with an updated date.
